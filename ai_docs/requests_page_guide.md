# Requests Page — User Guide

The Requests page lists HR requests you are allowed to see and lets you
filter, review, and open them.

## What you see
1. **Header** — "Requests" and a red **New request** button.
2. **Filter bar** — Search, Status, Request type, Date range, plus Clear and
   Apply. Managers and HR also see an "Awaiting my review" checkbox.
3. **Four summary cards** — Total Requests, Approved, Pending, Rejected, with
   each card's share of the filtered total.
4. **Table** — request type, submitter, status, submission date/time, current
   reviewer, and a ⋯ actions menu.
5. **Pagination** — under the table: "Page X of Y (N items)" and page arrows.

## Using the filters
1. Type in **Search** to match a request type, a submitter's name or email,
   or a reviewer role (e.g. "manager").
2. Pick a **Status** or **Request type** from the dropdowns.
3. Pick a **Date range** preset (All time, This week, …). Ranges apply to the
   request's submission date.
4. Click **Apply** to run the filters, or **Clear** to reset everything.

```
[Filters set] → [Apply] → [List + summary cards update]
                     ↓
              [Clear] → back to "All"
```

## Row actions
Click the ⋯ button on a row. You will see only the actions you are allowed to
perform (e.g. "View details", "Review" for the current approver, "Withdraw"
or "Resubmit" on your own requests). Choosing one opens the request page.

## Common mistakes
- The list looks empty after filtering — click **Clear** or use the
  "Clear filters" button in the empty state.
- "Pending" on the summary card counts requests still moving through review
  (Pending + In review), not just brand-new ones.

## FAQ
- **Why can't I see a colleague's request?** Visibility follows your role:
  employees see their own; managers see their team's; HR sees the permitted
  scope.
- **Where do I approve or reject?** Open the row — the review buttons live on
  the request detail page when it's your turn to act.
- **What does "—" in Current Reviewer mean?** The request is finished
  (approved, rejected, or cancelled) — no one is reviewing it.
